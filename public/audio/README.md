# SoulSelf Ambient Audio Assets

This directory contains high-fidelity audio loops (.mp3 format) focused on relaxing piano music and continuous natural flowing water:

* `piano-waterfall.mp3` - Relaxing acoustic piano melodies blended with continuous gentle flowing water (Default featured - inspired by Soothing Relaxation)
* `flowing-waterfall.mp3` - Gentle continuous waterfall and stream flowing over rocks
* `running-stream.mp3` - Soft stream water trickling peacefully over smooth stones
* `gentle-rain.mp3` - Soft rainfall on leaves for quiet reflection
* `forest-breeze.mp3` - Subtle breeze through trees and tranquil forest canopy
* `ocean-shore.mp3` - Gentle calm ocean waves rolling onto the sand

## Procedural Engine Fallback

SoulSelf also features a built-in zero-dependency Web Audio API procedural sound synthesizer. The application synthesizes soothing, organic, real-time procedural audio for relaxing piano and continuous flowing waterfall and stream ambience with seamless crossfading, soft volume curves, and non-distracting visual waves.
